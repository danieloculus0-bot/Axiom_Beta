# BEAN Gothic Lime — suite design system

The interface is **Mountain Dew if it went goth**: near-black charcoal, electric lime and restrained mint, with steel-colored text and clear hierarchy. **No orange branding.**

| Token | Value |
| --- | --- |
| Background | `#0F1113` |
| Surface | `#1A1D20` |
| Recessed surface | `#22282A` |
| Border | `#303A3B` |
| Primary text | `#E6EAE7` |
| Muted text | `#9FAEB0` |
| Lime accent | `#79DE4B` |
| Mint accent | `#52A86A` |

Keep the established four-step interface simple. Use the same nav, cards, forms, tables, status vocabulary and keyboard behavior throughout independent apps. Use lime for primary interaction, not as a substitute for approved status. Preserve drawing-revision/hash and inspection-review badges visibly. BEAN mascot animations stay subtle, with reduced-motion support. Shared styling must never couple the engineering calculations or data ownership to one front-end runtime.
