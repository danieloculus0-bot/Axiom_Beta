# Axiom Linux Package

Run:

```bash
./install.sh
```

Axiom installs for the current user under `~/.local` by default and does not require root.

Launch with:

```bash
axiom
```

Uninstall the application while preserving operational data:

```bash
./uninstall.sh
```

Only use `./uninstall.sh --purge-data` when you intentionally want to delete Axiom local database, audit journal and attachments.
