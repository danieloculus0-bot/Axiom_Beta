CAPABILITIES AND BOUNDARIES

What is real here?

Working in this browser

Selectable work orders and operation steps; a genuine elapsed-time clock; local start/stop event records; prevention of multiple active sessions for the same operator code; persistence in localStorage; drawing zoom and print; routing/drawing revision hold checks; and CSV/JSON export.

Fictional by design

Every job number, drawing, part, instruction, inspection note, work center and quantity is synthetic, created exclusively for this public demonstration. The drawing is an original generic SVG mockup, not a downloaded manufacturing print.

Not implemented on GitHub Pages

No live ECI JobBOSS² API connection, central clock database, time-ticket submission, payroll validation, user authentication, role/shift controls, manufacturing signoffs, official document release, or multi-device synchronization. Browsers cannot safely hold ERP API secrets on a public page.

Actual Axiom desktop direction

The server-connected Axiom application uses a separate Python backend, controlled drawing storage, and opt-in ERP adapters. Real JobBOSS integration requires authorized access and tested API mappings. This Pages demo does not claim that backend is active here.
